Part AHTML, CSS & JavaScript Fundamentals20 questions

1 D easyconceptHTML5 structure

Which declaration must appear at the very beginning of a document to define it as HTML5?

D<!DOCTYPE html>

HTML5 uses the short doctype <!DOCTYPE html> as the very first line of the document.

2 C easyconceptSemantic HTML

Which semantic element should wrap a site’s main navigation links?

C<nav>

<nav> is the semantic element for a block of navigation links. <navbar> is not a real HTML element.

3 D easyconceptAccessibility

What is the purpose of the alt attribute on an <img> element?

DIt provides alternative text for screen readers and when the image fails to load

alt supplies a text alternative used by assistive technology and shown if the image cannot be displayed.

4 B easyconceptCSS box model

In the CSS box model, which property adds space INSIDE the element, between its content and its border?

Bpadding

padding is inside the border; margin is the space outside the border.

5 A easyconceptCSS selectors

Which CSS selector targets the element written as <p id="total">?

A#total

# selects by id; . selects by class.

6 B easyconceptFlexbox

In Flexbox, which property aligns items along the MAIN axis?

Bjustify-content

justify-content works on the main axis; align-items works on the cross axis.

7 D easyconceptCSS Grid

Which declaration creates a grid of three equal-width columns?

Dgrid-template-columns: repeat(3, 1fr);

repeat(3, 1fr) creates three columns that each take one equal fraction of the free space.

8 C mediumconceptCSS specificity

A single paragraph is matched by an element selector, a class selector and an id selector, each setting a different colour. Which declaration is applied?

CThe id selector, because it has the highest specificity

Specificity ranks id above class above element. Source order only breaks ties between declarations of equal specificity.

9 A easyconceptVariables

Which keyword declares a variable that cannot be reassigned?

Aconst

const prevents reassignment of the binding (object contents can still change).

10 A easytrue / falseEquality operators

True or False: === compares both value and type, while == performs type coercion before comparing.

ATrue — === is strict equality and checks type as well as value

=== is strict: no coercion, types must match. == coerces, so "5" == 5 is true but "5" === 5 is false.

11 C mediumoutputType coercion

What is printed by the following code?

console.log(typeof "5" + 5);
console.log("5" - 2);

Cstring5 then 3

typeof "5" is the string "string", and "string" + 5 concatenates to "string5". The - operator has no string meaning, so "5" - 2 coerces to 3.

12 D easyconceptArray methods

Which array method creates a NEW array containing only the elements that pass a test?

Dfilter()

filter() returns a new array of the elements for which the callback returned true. forEach() returns undefined.

13 C mediumfind the bugLoop bounds

The function below should total the array but prints NaN. What is the bug?

function getTotal(items) {
  let total = 0;
  for (let i = 0; i <= items.length; i++) {
    total += items[i];
  }
  return total;
}
console.log(getTotal([10, 20, 30]));

CThe condition i <= items.length runs one iteration too many, so items[3] is undefined and the total becomes NaN

Valid indexes are 0 to length-1. Using <= reads items[3] (undefined); adding undefined to a number gives NaN. Use i < items.length.

14 D easyconceptDOM selection

Which method returns the FIRST element that matches a CSS selector?

Ddocument.querySelector()

querySelector returns the first match; querySelectorAll returns all matches as a NodeList.

15 D easyconceptDOM events

Which line correctly runs the function handleClick when the button is clicked?

Dbtn.addEventListener("click", handleClick);

Pass the function reference, not a call. handleClick() would run immediately and register its return value instead.

16 B easyconceptDestructuring

Given const user = { name: "Light", role: "admin" }, which statement uses destructuring to create a variable called name?

Bconst { name } = user;

Object destructuring uses curly braces and matches the property by name.

17 B mediumconceptArrow functions

Which arrow function correctly returns double its argument?

Bconst double = n => n * 2;

A concise body returns the expression automatically. With a block body ({ }) you must write an explicit return, so option A returns undefined.

18 C easyconceptJSON

What does JSON.stringify(obj) do?

CConverts a JavaScript object into a JSON string

stringify serialises an object to a JSON string; JSON.parse does the reverse.

19 A mediumconceptReference semantics

After const a = { count: 1 }; const b = a; what has been copied into b?

AA reference to the same object, so a change made through b is visible through a

Objects are assigned by reference. const only prevents reassigning the variable; the shared object can still be mutated.

20 B hardoutputHoisting & the TDZ

What happens when the following code runs?

console.log(x);
var x = 10;

console.log(y);
let y = 20;

BIt prints undefined, then throws a ReferenceError for y

var declarations are hoisted and initialised to undefined. let is hoisted but sits in the Temporal Dead Zone, so reading it before its declaration throws a ReferenceError.

Part BAsynchronous JavaScript8 questions

21 C easyconceptPromises

A Promise represents:

CThe eventual result of an asynchronous operation — pending, fulfilled, or rejected

A Promise is a placeholder for a future value and is always in one of three states.

22 D easyconceptasync functions

What does an async function always return?

DA Promise

Any value returned from an async function is automatically wrapped in a resolved Promise.

23 C mediumconceptEvent loop

A callback passed to setTimeout with a delay of 0 milliseconds will run:

CAfter all of the currently running synchronous code has finished

The callback is queued and can only be taken by the event loop once the call stack is empty, no matter how small the delay is.

24 A hardoutputMicrotasks vs macrotasks

What is the output order of the following code?

console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");

A1 4 3 2

Synchronous lines run first (1, 4). The event loop then drains the microtask queue (the Promise callback, 3) before macrotasks such as setTimeout (2).

25 C easytrue / falseawait rules

True or False: await may be used at the top of any ordinary (non-async) function.

CFalse — await is only valid inside an async function (or at the top level of a module)

Using await inside a normal function is a syntax error; the enclosing function must be declared async.

26 A mediumconceptfetch + await

Inside an async function, which pair of statements correctly retrieves and parses JSON from an endpoint?

Aconst res = await fetch(url); const data = await res.json();

fetch() returns a Promise that resolves to a Response, and .json() itself returns a Promise — so both calls must be awaited.

27 B easyconceptFetch API

What does fetch() return?

BA Promise that resolves to a Response object

fetch resolves to a Response; you then call .json() (which also returns a Promise) to read the body.

28 B mediumconceptError handling

Which is the correct way to handle an error thrown by an awaited call?

Btry { const d = await getData(); } catch (err) { console.log(err); }

await turns a rejected Promise into a thrown error, so try/catch is the natural way to handle it.

Part CNode.js8 questions

29 B easyconceptWhat Node.js is

Node.js is best described as:

BA JavaScript runtime built on Chrome’s V8 engine that runs JavaScript outside the browser

Node takes the V8 engine out of the browser and adds server-side APIs such as file system and HTTP.

30 A easyconceptpackage.json

What is the main purpose of package.json?

AIt records project metadata, scripts, and the list of dependencies

package.json describes the project and lets npm install rebuild node_modules from the dependency list.

31 C easyconceptModules

Which line makes a function available to other files in a Node.js (CommonJS) project?

Cmodule.exports = myFunction;

CommonJS exports through module.exports (or exports.name). window does not exist in Node.

32 D easyconceptrequire()

In a CommonJS project, which statement imports a local module named math.js from the same folder?

Dconst math = require("./math");

CommonJS uses require(), and local files need a relative path beginning with ./ — otherwise Node looks in node_modules.

33 A easytrue / falsenpm install & node_modules

True or False: npm install reads package.json and downloads the listed dependencies into the node_modules folder.

ATrue — package.json lists what the project needs and npm install fetches those packages into node_modules

package.json records the dependency list; npm install resolves it and places the packages, plus their own dependencies, into node_modules.

34 A mediumconceptSemantic versioning

In "express": "^4.21.2", what does the caret (^) allow npm to install?

AAny 4.x.x release at or above 4.21.2 (minor and patch updates, but not version 5)

^ allows changes that do not modify the left-most non-zero digit — that is, minor and patch updates within the same major version.

35 D easyconceptHTTP server

Which statement creates a plain Node HTTP server listening on port 3000?

Dhttp.createServer(handler).listen(3000);

createServer() builds the server with a request handler; .listen(port) starts it.

36 D easyconceptCore modules

Which built-in Node.js module provides functions for reading and writing files?

Dfs

The fs (file system) module provides readFileSync, writeFileSync and their asynchronous equivalents. path only builds and resolves file paths.

Part DExpress.js, Pug & MVC10 questions

37 D easyconceptMiddleware

In Express, middleware is:

DA function with access to req, res and next that runs during the request/response cycle

Middleware sits in the pipeline; it can inspect or modify the request and either respond or call next().

38 A easyconceptRouting

Which line handles a GET request to /about?

Aapp.get("/about", handler);

app.get(path, handler) registers a handler for the GET method on that path.

39 D easyconceptRoute parameters

In app.get("/anime/:id", ...), how do you read the id value?

Dreq.params.id

Named route segments (:id) arrive in req.params.

40 C easyconceptQuery strings

For the request GET /search?title=naruto, how is "naruto" read?

Creq.query.title

Everything after the ? is parsed into req.query.

41 C mediumfind the bugBody parsing

A Pug form is submitted with method="POST" but the handler below always logs undefined. What is missing?

app.post("/add", (req, res) => {
  console.log(req.body.title);   // undefined
  res.redirect("/");
});

Capp.use(express.urlencoded({ extended: true })) has not been registered

Express does not parse request bodies by default. express.urlencoded() populates req.body for HTML form posts.

42 A mediumtrue / falsenext() and the pipeline

True or False: middleware that neither sends a response nor calls next() will leave the request hanging.

ATrue — the request stops at that middleware, so no later route handler ever runs

Every middleware must either end the response or call next(). If it does neither, the pipeline stalls and the browser waits until it times out.

43 D easyconceptRouters

What is express.Router() used for?

DSplitting routes into separate, focused files that are mounted with app.use()

A Router groups related routes in their own file, keeping app.js small.

44 B mediumconceptMount paths

app.js contains app.use("/anime", animeRoutes) and the router file defines router.get("/:id", ...). Which URL does that route answer?

B/anime/42

The mount path is a prefix, so the router’s "/:id" becomes "/anime/:id".

45 A easyconceptRendering views

Which response method renders a Pug template and sends the resulting HTML?

Ares.render("index", { title })

res.render() compiles the named view with the supplied locals and sends the HTML.

46 B mediumoutputPug templates

What HTML does the Pug snippet below produce?

ul
  each item in ["A", "B"]
    li= item

B<ul><li>A</li><li>B</li></ul>

each loops the array and indentation nests the li inside the ul. The = outputs the value of the variable rather than the literal text.

Part EDatabases — MongoDB & Mongoose10 questions

47 A easyconceptNoSQL

MongoDB is best described as:

AA NoSQL document database that stores JSON-like documents

MongoDB stores flexible, JSON-like documents rather than fixed-schema tables.

48 D easyconceptTerminology

In MongoDB, a collection is most similar to which relational concept?

DTable

database → collection → document maps to database → table → row.

49 B easyconceptMongoose

Mongoose is:

BAn ODM library that models MongoDB data for Node.js

Mongoose is an Object Data Modeling layer providing schemas, validation and CRUD helpers on top of MongoDB.

50 C easyconceptModels & collections

mongoose.model("Anime", animeSchema) will read and write which collection?

Canimes

Mongoose lower-cases and pluralises the model name, so "Anime" maps to the animes collection.

51 C mediumoutputfind vs findOne

No document in the collection has a rating of 100. What does the code print?

const a = await Anime.find({ rating: 100 });
const b = await Anime.findOne({ rating: 100 });
console.log(Array.isArray(a), b);

Ctrue null

find() always resolves to an array (empty when nothing matches); findOne() resolves to null when there is no match.

52 A easyconceptQuery operators

Which query returns all anime with a rating of 9 or higher?

AAnime.find({ rating: { $gte: 9 } })

$gte means "greater than or equal" and is placed inside the field’s object. find returns every match.

53 A mediumconceptCombined filters

Anime.find({ studio: "Madhouse", year: { $lt: 2010 } }) returns documents that:

Amatch both conditions (AND)

Multiple keys in one filter object are combined with AND. Use $or for an either/or query.

54 C mediumtrue / falseupdateOne vs updateMany

True or False: updateOne() modifies every document that matches the filter.

CFalse — updateOne changes only the first match; updateMany changes every match

updateOne stops after the first matching document. Use updateMany to change every match.

55 C mediumfind the bugMissing await

The list page renders empty and the view cannot loop over the data. What is wrong?

exports.index = async (req, res) => {
  const anime = Anime.find();
  res.render("index", { anime });
};

Cawait is missing — anime holds a Promise instead of the array of documents

Every Mongoose query returns a Promise. Without await the template receives the Promise object, not the documents.

56 D hardconceptDestructive queries

What is the effect of await Anime.deleteMany({}) ?

DIt deletes every document in the collection

An empty filter matches all documents, so deleteMany({}) empties the entire collection — a well-known production hazard.

Part FSessions & Authentication9 questions

57 A easytrue / falseStateless HTTP

True or False: HTTP is a stateless protocol.

ATrue — each request is independent and the server keeps no memory of earlier requests on its own

Each request runs the application from scratch, which is exactly why sessions and tokens are needed.

58 B easyconceptBasic authentication

Basic authentication is considered very insecure mainly because:

BCredentials are sent with every single request and there is no login/logout system

Sending the username and password on every request greatly increases exposure, and there is no session to end.

59 D easyconceptSession flow

After a successful login using session authentication, what does the browser store?

DA session ID, held in a cookie, that it sends automatically on later requests

The server keeps the session data; the browser only carries the session id in a cookie.

60 B easyconceptCookies vs sessions

Which statement correctly contrasts cookies and sessions?

BCookies are stored client-side and can be modified or disabled by the user, while session data is stored server-side

Cookies are small, client-side and user-editable; sessions live on the server and cannot be tampered with by the user.

61 B mediumconceptEnding a session

Which call ends a user’s session in an Express application?

Breq.session.destroy()

req.session.destroy() removes the session from the server store — the standard logout step.

62 A mediumconceptPassword storage

When a new user registers, how should their password be stored?

AAs a salted one-way hash created with bcrypt, then verified at login with compareSync

Passwords must never be recoverable. bcrypt stores a salted one-way hash; at login the typed password is hashed and compared — never decrypted.

63 C easyconceptJWT structure

A JSON Web Token is made of three base64url parts in which order?

Cheader . payload . signature

A JWT is header.payload.signature — the header names the algorithm, the payload carries the claims, the signature protects both.

64 B hardconceptJWT integrity

An attacker edits the payload of a valid JWT but leaves the original signature untouched. What happens at jwt.verify()?

BIt throws — the signature no longer matches the recomputed header.payload, so the token is rejected

The signature is computed over header.payload with the secret. Changing the payload invalidates it, which is exactly how tampering is detected.

65 B mediumconceptJWT confidentiality

Which statement about the payload of a JSON Web Token is correct?

BIt is only base64url-encoded, so anyone holding the token can read it — secrets must never be placed inside it

A JWT is signed, not encrypted. The signature prevents tampering, but the header and payload are merely encoded and are readable by anyone with the token.
